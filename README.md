# Desafio de Projeto: Relatório Elaborado com Sample Financials - Power BI

## 📊 Descrição do Projeto
Este repositório contém a entrega do desafio prático do curso de Power BI. O objetivo deste projeto foi criar um relatório elaborado e interativo utilizando a base de dados de amostra `Financials` do Power BI, aplicando conceitos avançados de layout, navegabilidade e interatividade.

## 🎯 Objetivos e Requisitos Alcançados
O relatório foi desenvolvido seguindo rigorosamente as diretrizes do desafio:
- **Estrutura de Layout:** Definição clara de objetos para organizar o layout de forma limpa e profissional.
- **Navegabilidade:** Implementação de botões de navegação interativos entre as páginas do relatório.
- **Filtros e Segmentação:** Uso de segmentadores de dados (filtros dinâmicos) e botões associados a imagens para melhorar a experiência do usuário.
- **Alternância de Visuais:** Utilização avançada de **Indicadores (Bookmarks)** combinados com botões para permitir a seleção e visualização de diferentes gráficos sobre o mesmo assunto no mesmo espaço da tela.

## 📑 Estrutura do Relatório
O projeto é composto por duas páginas principais:

### Página 1: Visão Geral e Navegabilidade
Construída com base no passo a passo guiado, contendo:
- Layout estruturado com objetos de fundo.
- Visuais descritivos analisando os dados financeiros (lucro, vendas, unidades vendidas).
- Segmentadores de dados dinâmicos.
- Menu de navegação lateral/superior utilizando botões estilizados.

### Página 2: Análise Aprofundada (Criação Autoral)
Segunda página desenvolvida de forma independente, focada em expandir os *insights* da primeira página, mantendo a identidade visual, a interatividade e a navegabilidade através dos botões de retorno/avanço.

## 🛠️ Ferramentas e Técnicas Utilizadas
- **Power BI Desktop:** Modelagem, tratamento e criação de visuais.
- **Power BI Service:** Publicação e compartilhamento em nuvem.

- **Indicadores (Bookmarks) & Ações de Botões:** Para alternância de telas e sobreposição de gráficos.
